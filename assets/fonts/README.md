# Flyer fonts

The flyer generator uses the variable TrueType files for Cormorant Garamond and Manrope from the Google Fonts repository.

- Cormorant Garamond: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope

Both font families are distributed under the SIL Open Font License 1.1.
